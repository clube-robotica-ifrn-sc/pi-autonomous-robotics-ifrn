# Esquemáticos e pinagem

Documentação das conexões elétricas e da interface entre o shield e o Arduino Mega.

- [Pinagem oficial](pinagem.md): sinais, conectores, alimentação e pendências de montagem.

Cada alteração deve informar a revisão do hardware, a fonte da pinagem e a data de conferência. O diagrama usado para montagem deve corresponder à placa instalada.
