# Hardware

Diretório destinado aos itens físicos do projeto.

## Organização sugerida

- `esquematicos/`: diagramas elétricos e conexões.
- `3d/`: peças e modelos mecânicos.
- `componentes/`: lista de materiais e fornecedores.

## Objetivo

Centralizar documentação e arquivos físicos do robô para facilitar manutenção e reprodução do protótipo.
