# Documentação

Esta pasta reúne toda a documentação técnica, acadêmica e de acompanhamento do projeto.

## Conteúdo sugerido

- `arquitetura/`: visão geral do robô, blocos funcionais e decisões de design.
- `teoria/`: fundamentos de eletrônica, sensores, controle e robótica.
- `relatorios/`: registros de testes, reuniões e evolução do projeto.

## Regra

Toda alteração importante no projeto deve ser registrada aqui com data, objetivo e resultado observado.
