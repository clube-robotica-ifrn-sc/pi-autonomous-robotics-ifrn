# Documentação

Esta pasta reúne a documentação técnica, acadêmica e de acompanhamento do projeto. Os materiais são separados por finalidade para facilitar consulta, atualização e continuidade do trabalho.

## Organização

| Área | Conteúdo principal |
| --- | --- |
| [`arquitetura/`](arquitetura/README.md) | Subsistemas, interfaces e decisões técnicas |
| [`obr/`](obr/) | Regulamentos, requisitos e checklist por edição |
| [`relatorios/`](relatorios/README.md) | Projeto de pesquisa, planejamento, testes e evidências |
| [`teoria/`](teoria/README.md) | Eletrônica, sensores, controle e robótica |

## Fluxo de uso

1. Consulte a arquitetura e os requisitos da OBR antes de alterar hardware ou firmware.
2. Registre cada atividade no [plano de execução](relatorios/Plano-de-Execucao.md).
3. Use o [modelo de teste](relatorios/Modelo-de-Registro-de-Teste.md) para ensaios de bancada e integração.
4. Atualize o cronograma somente com base em evidências vinculadas.

## Registro de alterações

Registre alterações técnicas relevantes nos documentos da área correspondente. Para testes e atividades, informe data, objetivo, método, resultados observados e conclusão; diferencie resultados medidos de metas planejadas.
