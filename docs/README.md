# Documentação

Esta pasta reúne a documentação técnica, acadêmica e de acompanhamento do projeto. Os materiais são separados por finalidade para facilitar consulta, atualização e continuidade do trabalho.

## Organização

- [`arquitetura/`](arquitetura/README.md): visão geral dos subsistemas e decisões técnicas.
- [`obr/`](obr/): regulamentos e materiais da OBR organizados por ano; consulte [`obr/2026/`](obr/2026/README.md) para o checklist desta edição.
- [`relatorios/`](relatorios/README.md): registros de testes, reuniões e evolução do projeto.
- [`teoria/`](teoria/README.md): fundamentos de eletrônica, sensores, controle e robótica.

## Registro de alterações

Registre alterações técnicas relevantes nos documentos da área correspondente. Para testes e atividades, informe data, objetivo, método, resultados observados e conclusão; diferencie resultados medidos de metas planejadas.
