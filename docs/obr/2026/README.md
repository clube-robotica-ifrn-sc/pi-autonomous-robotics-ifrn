# OBR 2026

Documentos de inscrição, regras, aplicação e acompanhamento da Olimpíada Brasileira de Robótica em 2026.

## Arquivos

- `Checklist-OBR-2026.md`: checklist de conformidade da equipe.
- `Checklist-OBR-2026.docx`: versão editável para impressão ou compartilhamento.

Os arquivos Markdown e DOCX devem permanecer com o mesmo conteúdo. Quando um item for confirmado, atualize as duas versões.
