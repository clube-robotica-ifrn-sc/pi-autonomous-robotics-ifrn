# Base Teórica

Este diretório reúne a fundamentação técnica do projeto.

## Temas sugeridos

- eletrônica digital;
- microcontroladores Arduino;
- sensores e atuadores;
- controle PID;
- lógica de programação;
- robótica autônoma e atuação em ambientes competitivos.

## Importância

A documentação teórica permite reduzir retrabalho e facilitar a compreensão de decisões técnicas durante o desenvolvimento.
