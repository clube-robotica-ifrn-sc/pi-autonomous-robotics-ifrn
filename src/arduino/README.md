# Firmware Arduino

Código embarcado para o Arduino Mega 2560.

## Organização

- [`Tinkerer/`](Tinkerer/): firmware principal em integração.
- [`testes/`](testes/): sketches independentes para validação de bancada.

Carregue apenas um sketch de teste por vez. Registre placa, pinagem, alimentação, versão do código e resultado no modelo de teste antes de integrar alterações ao firmware principal.
