# Componentes do robô no sBotics

As abreviações identificam os componentes do robô em relação à frente do robô: `F` (frente), `B` (trás), `L` (esquerda), `R` (direita) e `M` (centro).

## Servomotores de tração

| Abreviação | Significado |
| --- | --- |
| `sfr` | Servo frontal direito (*Servo Front Right*) |
| `sfl` | Servo frontal esquerdo (*Servo Front Left*) |
| `sbl` | Servo traseiro esquerdo (*Servo Back Left*) |
| `sbr` | Servo traseiro direito (*Servo Back Right*) |

## Sensores ultrassônicos

| Abreviação | Significado |
| --- | --- |
| `uf` | Ultrassônico frontal (*Ultrasonic Front*) |
| `ul` | Ultrassônico esquerdo (*Ultrasonic Left*) |
| `ur` | Ultrassônico direito (*Ultrasonic Right*) |

## Sensores de cor

| Abreviação | Significado |
| --- | --- |
| `cfr` | Sensor de cor frontal direito (*Color Front Right*) |
| `cfl` | Sensor de cor frontal esquerdo (*Color Front Left*) |
| `cll` | Sensor de cor esquerdo externo (*Color Left Left*) |
| `cl` | Sensor de cor lateral esquerdo (*Color Left*) |
| `cm` | Sensor de cor central (*Color Middle*) |
| `cr` | Sensor de cor lateral direito (*Color Right*) |
| `crr` | Sensor de cor direito externo (*Color Right Right*) |

## Sensores de toque

| Abreviação | Significado |
| --- | --- |
| `tr` | Sensor de toque traseiro direito (*Touch Right Back*) |
| `tl` | Sensor de toque traseiro esquerdo (*Touch Left Back*) |

O modelo do robô e o código devem ser atualizados juntos quando um componente mudar. A pinagem do robô físico está documentada em [`hardware/esquematicos/pinagem.md`](../../hardware/esquematicos/pinagem.md).
