# Simulação sBotics

Código e arquivos do robô virtual.

- [`code/`](code/): controle em C# para o ambiente sBotics.
- [`robots/`](robots/): modelo do robô virtual.
- [components.md](components.md): nomes dos sensores e atuadores usados pelo código.

Registre a versão do simulador, o cenário, as condições de execução e os resultados sempre que um comportamento for validado.
